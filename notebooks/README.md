# notebooks/

노트북은 **오케스트레이션 전용**입니다. 계산은 `src/hicpy/`, 실행 가능한 파이프라인은
`scripts/`와 `analysis/`에 둡니다. 노트북이 함수 정의로 가득 차면 테스트도
재사용도 불가능해집니다.

규칙:
- 실행 순서대로 번호를 붙입니다: `01_*.ipynb`, `02_*.ipynb`
- 커밋 전에 반드시 **Restart & Run All**이 위에서 아래로 깨끗이 통과해야 합니다.
  셀을 뒤죽박죽 실행한 상태(hidden state)는 재현 불가능한 물리 결과의 최대 원인입니다.

Module 1은 스크립트만으로 완결되므로 아직 노트북이 없습니다.
Module 2(PYTHIA) 탐색 단계에서 첫 노트북을 추가할 예정입니다.
