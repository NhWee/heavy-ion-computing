## 2. 생성 스크립트 — `scripts/m02_run_pythia.py`

Module 1과 **같은 TTree 브랜치**(`nparticle`, `particle_px/py/pz/E/pdg`, `has_z`)를
쓰고, 거기에 Module 2가 필요한 브랜치를 **더합니다**:

| 브랜치 | 용도 |
|---|---|
| `particle_charge` | 하전입자 선택 (`≠ 0`). Module 1 분석도 이 브랜치를 쓴다 (§5) |
| `process_code` | 101 ND, 103/104 SD, 105 DD, 106 CD → NSD 선택 |
| `n_ch_eta1` | \|η\|<1 하전입자 수 → INEL>0 선택 |
| `weight` | 이벤트 가중치 (MB는 1) |

provenance에는 카드 **전문**, PYTHIA 버전, seed, `sigmaGen ± err` (mb), 시도/수락
이벤트 수, git 커밋이 들어갑니다. 단면적이 있어야 "이벤트 수"를 "mb"로 바꿔
데이터와 정규화를 맞출 수 있습니다.

`--hepmc`를 주면 HepMC3 파일도 씁니다 (Module 3용; 이 pythia8 빌드에 HepMC
인터페이스가 없으면 경고만 내고 무시).

## 4. 데이터 비교 (다음 단계)

1. `data/raw/README.md`의 템플릿대로 ALICE pp 13 TeV $dN_{\rm ch}/d\eta$ (INEL>0)
   provenance JSON을 **먼저** 채우고 HEPData에서 표를 받는다.
2. `analysis/m02_compare_data.py` (작성 완료, toy로 테스트됨): 이벤트 클래스
   (INEL / INEL>0 / NSD)를 **입자와 process code에서 계산**해 적용 → 데이터의
   η bin으로 직접 히스토그램 → ratio panel(통계·계통 분리) → |η|<0.5 평균의
   MC/data 판정(±15 %) → `results/tables/m02/m02_compare_summary.json`.
   - 데이터는 provenance JSON을 통해서만 읽는다(템플릿이 안 채워져 있으면 거부).
     HEPData YAML(정식)과 CSV export 둘 다 읽는다.
   - **pT cut 없음** (`comparison.dndeta_pt_min = 0`): 발표된 dN/dη는 pT = 0으로
     외삽한 값이라 Module 1의 0.15 GeV/c cut을 걸면 안 된다. 이것이 Module 1
     히스토그램을 그대로 쓰지 않는 이유.
   - 데이터 없이도 돈다 (`--no-data`): MC만 그리고 판정은 null.
   ```bash
   python analysis/m02_compare_data.py --config config/analysis_m02_pythia.yaml
   ```
3. 판정: $dN_{\rm ch}/d\eta|_{|\eta|<0.5}$가 측정의 ±15 % 이내. 벗어나면 tune 차이보다
   설정 오류(primary 정의, 이벤트 클래스, 하전입자 정의)를 먼저 의심.

## 5. 결정됨 — "하전입자"의 정의 → (a) `particle_charge ≠ 0` (2026-11-05)

Module 1 분석의 `CHARGED_HADRONS = {211, 321, 2212}`는 toy 생성기의 산물입니다.
PYTHIA 샘플에서 이대로 세면 ALICE의 "charged primary"보다 수 % 적게 셉니다
(e±, μ±, Σ±, Ξ±, Ω±가 빠짐). 선택지:

- (a) 분석을 `particle_charge != 0`로 바꾸고 toy 파일에도 `charge` 브랜치를 추가
  (Module 1 결과 재생성; 값은 동일해야 함 — 그것 자체가 검증)
- (b) Module 1 분석은 그대로 두고 Module 2 비교 스크립트만 charge를 사용

**(a)로 결정·반영 완료**: toy 생성기와 writer에 `charge` 브랜치를 추가하고 세 arm의
분석을 `particle_charge ≠ 0`으로 바꿨다. "같은 분석 코드가 수정 없이 돈다"는 목표의
참뜻은 "입력이 바뀌어도 정의가 흔들리지 않는다"이고, 그러려면 정의가 입력의
우연(toy에 π/K/p뿐)이 아니라 물리(전하)에 걸려 있어야 한다. Module 1 결과는
뮤온 두 개만큼 바뀌었고(`module01_root.md`), 그 과정에서 float32 히스토그램 버그
(오답노트 #12)를 찾았다. 따라서 `m02_run_pythia.py`가 쓰는 `particle_charge`(int8)는
Module 1 파일과 같은 브랜치·dtype이다.

## 7. 결과와 원인 분석 (2026-11-19)

**결과** (WSL2, PYTHIA 8.312, 20k): ALICE INEL>0 dN/dη, |η| < 0.4 —
MC 6.84 ± 0.05, data 6.44 ± 0.19 → **MC/data = 1.06** (약 2σ). η 모양은 재현, 크기만 3–7 % 높음.

**원인 좁히기** — `scripts/m02_run_variations.sh` + `analysis/m02_sensitivity.py`
(클라우드, PYTHIA 8.318; 같은 버전 nominal 대비 상대값으로 읽을 것):

| 변형 | MC/data (INEL>0) | nominal 대비 | 의미 |
|---|---|---|---|
| nominal (Monash) | 1.076 | — | |
| colour reconnection off | 1.473 | +37 % | CR이 다중도를 크게 줄이는 손잡이 |
| Tune 4C | 1.150 | +7 % | 이전 기본 튠은 더 나쁨 |
| MPI pT0Ref 2.28 → 2.40 | 1.039 | −3.4 % | **+9 % 정도면 6 %가 사라짐** |
| 모든 붕괴 허용 | 1.177 | +9.5 % | primary 정의를 틀렸다면 생겼을 차이 |

1. **primary 정의**: ALICE (arXiv:1509.08734) = "충돌의 prompt 입자와 그 모든 붕괴 산물,
   단 strange 입자의 약붕괴 산물 제외". 카드의 `tau0Max = 10 mm`가 정확히 이것
   (K0S, Λ, Σ±, Ξ, Ω 모두 cτ ≥ 2.4 cm → 붕괴 안 함; 참·바닥 붕괴 산물은 포함). → 원인 아님.
2. **이벤트 클래스**: INEL>0을 입자에서 직접 계산 → 정의 동일. 같은 표의 INEL 열과 비교하면
   데이터가 스스로 f(INEL>0) = 5.285 / 6.44 = **0.821**을 정해 준다 (|η| < 1에서
   dN/dη(INEL) = f × dN/dη(INEL>0)이 정확히 성립). PYTHIA는 0.86 → INEL 비교에는 회절 모델
   차이로 약 5 %가 **따로** 더해진다 (1.076 × 0.860/0.821 = 1.128 vs 측정 1.127).
3. **모델**: dN/dη는 MPI·CR에 매우 민감. Monash는 ≤ 7 TeV 데이터로 맞춘 뒤 pT0를 거듭제곱으로
   13 TeV에 외삽한다. 6 %는 이 외삽의 오차로 자연스럽게 설명되는 크기다.
   (아직 하지 않은 것: pT0Ref를 실제로 맞춰 보기 — 그것은 "튜닝"이고, 다른 관측량 없이
   dN/dη 하나로 하면 과적합이다. → 아래 §8의 pT 스펙트럼이 두 번째 제약.)

**Module 1 분석 재사용**: `m01_analysis_uproot.py --config config/analysis_m02_pythia.yaml`
이 수정 없이 끝까지 돈다 (로드맵 기준 충족). Tsallis χ²/ndf = 29는 물리(질량 혼합 + hard
꼬리), Z fit은 후보 0개라 이제 시도하지 않는다 (#19).

## 8. 두 번째 관측량: pT 스펙트럼 (ALICE Table 2, 2026-11-19)

`analysis/m02_compare_pt.py` — 불변 수율 (1/2π pT) d²N/dη dpT, |η| < 0.8, INEL>0,
0.15–20 GeV/c 47 bins, 통계·계통 분리. 표는 브라우저로 받아 `--local`로 검증.
MC: 클라우드 nominal (PYTHIA 8.318, 20k) — `results/tables/m02/m02_compare_pt_summary.json`,
`results/figures/m02/m02_pt_vs_data.png`.

**결과**: 초과는 균일하지 않다. MC/data가 0.15 GeV/c에서 **0.86**, 0.5 GeV/c에서 **1.24**,
1–2 GeV/c에서 ~1.08, 2–8 GeV/c에서 ~1.2. 적분(0.15–20 GeV/c) 1.09 — dN/dη 결과(1.076)와 일치.
⟨pT⟩(0.15–20): ALICE 0.647, Monash 0.667 (**+3 %**). PYTHIA 스펙트럼이 약간 단단하다.

| 변형 | ⟨pT⟩ MC/data | 0.15–0.25 | 0.4–0.8 | 1–4 GeV/c |
|---|---|---|---|---|
| nominal | 1.030 | 0.905 | 1.191 | 1.153 |
| CR off | 0.858 | 1.410 | 1.707 | 0.764 |
| Tune 4C | 1.028 | 0.986 | 1.238 | 1.210 |
| pT0Ref 2.40 | 1.022 | 0.884 | 1.148 | 1.072 |
| 모든 붕괴 | 1.006 | 1.044 | 1.268 | 1.167 |

**해석**
- MPI 컷오프(pT0Ref)는 **크기**를 움직이고 **모양**(⟨pT⟩)은 거의 그대로 둔다 (−0.8 %).
  dN/dη만 보면 pT0Ref ≈ 2.5 GeV로 맞출 수 있지만, 0.15–0.25 GeV/c의 부족은 오히려 커진다.
- colour reconnection은 **모양**을 움직인다: 끄면 ⟨pT⟩가 14 % 내려가고 저 pT가 크게 는다.
- → 두 관측량을 함께 맞추려면 **MPI와 CR을 동시에** 다시 맞춰야 한다. dN/dη 하나로는
  구별할 수 없던 것을 pT 스펙트럼이 구별해 준다. 이것이 튠이 여러 관측량으로 만들어지는 이유.
- 다음(선택): pT0Ref × CR 강도(`ColourReconnection:range`) 2차원 격자 → dN/dη와 pT 스펙트럼의
  결합 χ². 계통 오차의 bin 간 상관을 모르면 χ²는 과대평가되므로, 그 전에 논문에서 상관 확인.

## 9. 2차원 스캔: MPI pT0Ref × CR range (2026-11-19)

`analysis/m02_tune_scan.py` (generate / fit), 20점 × 10k 이벤트 (클라우드, 8.318).
`results/tables/m02/m02_tune_scan.json`, `results/figures/m02/m02_tune_scan.png`.

**계통 오차 상관**: HEPData 표에는 bin 간 상관이 없다. 논문에서 확인되는 것은 INEL>0 정규화
1.2 %(모든 bin 공통)뿐. 그래서 두 극단으로 χ²를 계산: **uncorr** (stat ⊕ sys, bin 독립) /
**corr** (sys = 관측량마다 완전 상관된 정규화 하나, 해석적으로 profile). 진실은 그 사이.

| | uncorr: χ² dN/dη (18) · pT (47) | corr | dN/dη MC/data | ⟨pT⟩ MC/data |
|---|---|---|---|---|
| Monash (2.28, 1.8) | 61 · 261 | 62 · 936 | 1.08 | 1.03 |
| dN/dη 최적 (2.52, 1.4) | **3** · 113 | **18** · 893 | 0.999 | 0.999 |
| 결합 최적, uncorr (2.40, 2.6) | 16 · **89** | 48 · 900 | 0.990 | 1.032 |

**두 모형 모두에서 성립하는 결론**
1. dN/dη만으로는 **pT0Ref ≈ 2.5 GeV, CR range ≈ 1.4**가 최적 (Monash 2.28, 1.8). dN/dη χ²는
   pT0Ref–CR 대각선 골짜기를 그린다 — 둘이 서로 상쇄한다 (MPI를 줄이면 CR을 약하게).
2. **pT 스펙트럼 모양은 이 격자 어디서도 맞지 않는다**: sys를 정규화로만 보면 통계 오차만 남고,
   χ² ≥ 738 / 47. 0.15 GeV/c의 부족과 0.5 GeV/c의 초과는 이 두 파라미터 밖의 문제 — 후보는
   끈 조각화의 횡운동량 폭 (`StringPT:sigma`), CR 모형 자체, 회절 성분.
3. 이것은 **튠이 아니다**: 파라미터 2개, 에너지 1개, 실험 1개, 상관 모형은 가정.

## 10. 정식 결과 (WSL2, PYTHIA 8.312, 2026-11-19) — §7–9의 클라우드(8.318) 수치를 대체

`bash scripts/run_all_pythia.sh`로 Module 2–4 전체를 한 환경에서 재생성 (`1cc643e`).

**민감도** (`results/tables/m02/m02_sensitivity.json`), ALICE INEL>0 dN/dη, |η| < 0.4 = 6.44 ± 0.19:

| 변형 | MC dN/dη | MC/data | nominal 대비 | ⟨pT⟩ MC/data |
|---|---|---|---|---|
| nominal (Monash) | 6.84 ± 0.05 | 1.062 | — | 1.035 |
| **pT0Ref 2.40** | 6.46 ± 0.05 | **1.003** | −5.6 % | 1.020 |
| CR off | 9.50 | 1.476 | +39 % | 0.868 |
| Tune 4C | 7.29 | 1.131 | +6.5 % | 1.040 |
| 모든 붕괴 | 7.47 | 1.159 | +9.2 % | 1.015 |

**pT 스펙트럼**: MC/data 0.85 (0.15–0.2 GeV/c) → 최대 1.23 (~0.5 GeV/c); 적분 1.079. ⟨pT⟩ 0.670 vs 0.647.

**2차원 스캔** (pT χ²는 0.15–5 GeV/c, 39 bins):

| 점 (pT0Ref, CR range) | uncorr χ² dN/dη · pT | corr χ² dN/dη · pT | dN/dη MC/data | ⟨pT⟩ MC/data |
|---|---|---|---|---|
| Monash (2.28, 1.8) | 45 · 255 | 54 · 1032 | 1.069 | 1.035 |
| **(2.40, 1.8)** | **6** · **93** | **29** · 858 | **1.004** | 1.023 |
| (2.52, 1.0) | 3 · 184 | 34 · 1210 | 1.006 | 0.975 |

**결론 (정식)**
1. **Monash의 CR은 그대로 두고 MPI pT0Ref만 2.28 → 2.40 GeV (+5 %)** 올리면 dN/dη가 맞는다 —
   변형 연구(1.003)와 스캔(1.004)이 독립적으로 같은 답. 스캔에서 이 점은 corr 모형의 dN/dη 최적이고
   uncorr 모형의 결합 최적이다.
2. pT 스펙트럼 모양은 여전히 안 맞는다 (corr χ² ≥ 635/39). 저 pT 부족·0.5 GeV/c 초과는 이 두 손잡이
   밖의 문제 → 다음 후보 `StringPT:sigma`.
3. 클라우드(8.318)와 결론이 같다: 숫자는 버전에 따라 1–2 % 움직이지만 (nominal 1.076 vs 1.062)
   방향과 최적점은 같다.

## 12. 종류별 스펙트럼: 0.4–0.8 GeV/c 초과는 어디서 오는가 (2026-11-20, WSL2 PYTHIA 8.312 정식)

**결론**
1. **초과는 π에서 온다** (Monash에서 +15 % 중 +14 %). 종류별 합이 하전입자 비교를 재현 —
   두 독립 측정(η vs y, 다른 논문)이 같은 그림을 준다.
2. π의 모양: 0.1–0.25에서 −18 %, 0.4–0.8에서 +17 % → **MC의 π 스펙트럼 봉우리가 데이터보다 높은 pT 쪽**.
   pT0Ref·σ 조정은 진폭을 +17 → +11 %로 줄일 뿐 모양은 그대로. 1차 끈 조각화보다는 공명 붕괴
   (ρ, ω, K* → π)로 만들어지는 π의 비중과 운동학, 또는 CR의 영향이 후보 — 다음에 붕괴 출처별로 나눠 본다.
3. **K와 p는 질량 순서의 다른 문제**: 저 pT 초과, 0.8 GeV/c 위 10–25 % 부족 → MC의 무거운 입자 스펙트럼이
   너무 부드럽다. 데이터는 질량이 클수록 단단해지는데(작은 계에서 보이는 radial-flow 같은 경향),
   Monash는 이를 다 만들지 못한다. pT0Ref·σ 조정은 K를 더 나쁘게 만든다 (0.8–1.5 GeV/c 0.83 → 0.73,
   수율 0.96 → 0.91). **π에 맞춘 조정이 K를 희생한다** — 손잡이 하나로 둘 다 맞출 수 없다는 뜻.
4. **K/π가 7–9 % 부족** — PYTHIA가 기묘도 생성을 덜 만드는 것은 알려진 문제. 같은 레코드의 다중도별
   K/π (Table 17)와 비교하면 다중도와 함께 커지는 기묘도 증가를 볼 수 있다 (다음 단계).
5. Module 1의 closure 교훈이 실데이터에서 다시: 하전입자 합 하나로는 π 모양 문제와 K·p 질량 순서 문제가
   서로 상쇄되어 보였다 (Monash, 1.5–3 GeV/c: π +20 %, K −18 % → 하전 합은 +5 % 정도).

## 13. π는 어디서 오는가 — 출처 분해와 원인 시험 (2026-11-20, 클라우드 8.318; WSL2 재현 대기)

`analysis/m02_pion_origin.py`: §12의 MC와 **같은 사건**(같은 카드·seed·루프)을 다시 만들면서 각 최종 π, K, p의
출처를 PYTHIA status 코드로 읽는다. |status| 81–89 = 끈 조각화에서 바로 나온 강입자("direct"),
91–99 = 붕괴 산물 → 바로 위 어미(ρ, ω, η, K*, Δ, …)로 분류. **closure**: 출처별 스펙트럼의 합이 §12의 MC
스펙트럼과 4 × 10⁻¹⁶까지 같다 (같은 사건임을 확인). 그림 `results/figures/m02/m02_pion_origin*.png`.

**Monash에서 π의 구성** (|y| < 0.5, 전 pT): direct 35 %, ρ 35 %, ω 16 %, η/η′ 5 %, K* 6 %, Δ 3 %.
평균 pT: **direct 0.64**, ρ 0.57, K* 0.44, ω 0.35, Δ 0.34, η 0.28 GeV/c — 직접 π가 가장 단단하고, 3체 붕괴(ω, η)
π가 가장 부드럽다. 0.1–0.25 GeV/c는 붕괴 π가 75 %, 0.4–0.8은 direct 40 % + ρ 39 %.

**원인 시험** — 지표는 모양 비 S = [MC/data, 0.4–0.8] / [MC/data, 0.1–0.25] (S = 1이면 그 구간의 모양이 맞다).
`analysis/m02_pion_origin_summary.py`, 각 20k 사건:

(χ²는 데이터 stat ⊕ sys를 상관 없다고 놓은 값 — 설정 사이의 순위로만 읽는다. Bose–Einstein과 재산란은 최종
입자의 status를 다시 써서 출처 분류는 무효, 합계만 유효.)

**결론**
1. **구성(조성)이 원인이 아니다.** 벡터 중간자 비를 0.25–1.5로 6배 바꿔도 S는 1.33–1.44. 벡터를 늘리면 저 pT
   부족은 메워지지만 ρ 붕괴 π(봉우리 ~0.5 GeV/c)가 0.4–0.8 초과를 같이 키운다. "직접 π ×0.5, 붕괴 π ×1.2"
   같은 성분 배율 맞춤은 숫자로는 χ²를 줄이지만, PYTHIA 안에서 그런 조합을 만드는 손잡이는 없다.
2. Bose–Einstein 상관은 모양을 바꾸지 않는다 (S 1.38).
3. **강입자 재산란이 지금까지 유일하게 S를 움직인다** (1.38 → 1.23). 끈 조각화 뒤 강입자끼리 충돌하면 가벼운
   π는 운동량을 잃고 무거운 p는 얻는다 — π의 0.4–0.8 초과와 p의 저 pT 초과(1.39 → 1.24)가 함께 줄어든다.
   pp에서도 고다중도 사건에서는 강입자 밀도가 충분히 높다는 것이 이 모형의 주장
   (Sjöstrand & Utheim, arXiv:2005.05658). 0.8 GeV/c 위의 K·p 부족은 거의 그대로 → 질량 순서 문제의 일부만 설명.
4. 앞의 조정(pT0Ref 2.40, σ 0.31)과 합치면 S 1.19, χ² 462 → 126. 그래도 π 0.4–0.8은 +11 %, 0.1–0.25는 −7 %,
   K는 0.8 GeV/c 위에서 20 % 부족 — **남은 모양 차이는 이 손잡이들 밖에 있다.** 후보: 끈들 사이의 집단 효과
   (rope hadronization, string shoving), 기묘도 생성(K/π 0.92).
5. 방법 메모: "어느 성분이 문제인가"(분해)와 "어떤 물리가 그 모양을 바꾸는가"(설정 시험)는 다른 질문이다.
   분해는 직접 π가 가장 단단하다는 것을 보여 줬지만, 실제로 모양을 움직인 것은 성분 비가 아니라 성분 사이의
   운동량 재분배(재산란)였다.
