## 0. 이 모듈이 답하는 질문

> Pb–Pb 충돌 하나에서 몇 개의 핵자가 부딪히고(N_part), 핵자–핵자 충돌은 몇 번 일어나는가(N_coll)?
> 실험의 "0–5 % 중심도"는 기하학적으로 무엇인가?

중이온 관측량은 거의 전부 이 두 숫자로 pp와 연결된다.

- **R_AA = yield_AA / (⟨N_coll⟩ × yield_pp)** — 하드 프로세스는 N_coll에 비례한다는 가정.
  Module 2의 pp 스펙트럼을 Pb–Pb 기대값으로 바꾸는 계수가 ⟨N_coll⟩ (또는 T_AA = ⟨N_coll⟩/σ_NN).
- 벌크 입자 생성(dN/dη)은 대략 N_part에 비례한다 → Module 4의 배경 밀도 ρ도 N_part와 함께 자란다.
- N_part, N_coll은 측정할 수 없다. **모형의 출력**이고, 그 불확실성은 모든 R_AA에 들어간다.

## 1. 모형 — `src/hicpy/glauber.py`

1. **핵 하나**: A = 208개 핵자를 Woods–Saxon 밀도에서 뽑는다.
   ρ(r) ∝ 1/(1 + exp((r − R)/a)), R = 6.62 fm, a = 0.546 fm (전자 산란으로 잰 전하 분포).
   반경은 r²ρ(r)의 역누적분포로, 방향은 등방으로. **hard core**: 두 핵자가 d_min = 0.4 fm보다 가까우면
   다시 뽑는다. 마지막에 질량 중심을 원점으로 (TGlauberMC와 같은 관례).
2. **충돌**: 충돌 변수 b를 dP ∝ b db (b < 20 fm)로 뽑고, 두 핵을 ±b/2만큼 옮겨 직선으로 통과시킨다.
3. **판정 (black disk)**: 핵자 쌍의 횡거리 d가 π d² < σ_NN 이면 충돌.
   σ_NN = 67.6 mb (5.02 TeV, pp 비탄성 단면적의 내삽). 1 mb = 0.1 fm² → 충돌 반경 1.47 fm.
4. **집계**: N_coll = 충돌한 쌍의 수, N_part = 한 번 이상 충돌한 핵자 수.
   σ_AA = π b_max² × (N_coll > 0 인 사건의 비율).
5. **중심도**: σ_AA의 백분위. 여기서는 b 순서(기하학적 정의). 실험은 측정 다중도 순서로 정하고,
   그 근사로 N_part 순서도 함께 계산한다.

입력과 출처:

| 입력 | 값 | 출처 |
|---|---|---|
| R, a (Pb-208) | 6.62 ± 0.06 fm, 0.546 ± 0.010 fm | ALICE, arXiv:1301.4361 |
| d_min | 0.4 ± 0.4 fm | 같은 곳 |
| σ_NN (5.02 TeV) | 67.6 ± 0.6 mb | arXiv:1710.07098 |

## 2. 검증

**(1) 핵 하나의 밀도** (`results/figures/m06/m06_density.png`): 뽑은 핵자의 반경 분포가 Woods–Saxon을
따르고, 중심 밀도 ≈ 0.16 핵자/fm³ — 핵물질 포화 밀도. d_min 조건은 테스트로 확인.

**(2) 단위 테스트** (`tests/test_m06_glauber.py`, 6개): ⟨r²⟩이 해석값과 1 % 이내, d_min 위반 없음,
b = 0이면 N_part > 380 (최대 2A = 416)이고 b = 25 fm면 충돌 없음, p–A에서 N_part = N_coll + 1 (양성자 하나가
모든 충돌에 참여), pp에서 σ = σ_NN, 중심도 클래스의 단조성.

**(3) ALICE 표와 비교** (ALICE-PUBLIC-2018-011, Pb–Pb 5.02 TeV, TGlauberMC):

| 클래스 | ⟨N_part⟩ 이 코드 (b 순서 / N_part 순서) | ALICE | ⟨N_coll⟩ 이 코드 | ALICE |
|---|---|---|---|---|
| 0–1 % | 405.0 / 406.0 | 401.9 | 1977 / 1959 | 1949 |
| 4–5 % | 362.3 / 363.1 | 362.9 | 1596 / 1595 | 1593 |

4–5 %는 0.2 % 이내로 일치. 0–1 %의 +0.8 %(N_part), +1.4 %(N_coll, b 순서)는 이 클래스에서 b 순서와
다중도 순서가 가장 크게 다르기 때문 — N_part 순서로 바꾸면 N_coll 차이가 +0.5 %로 줄어든다.

**(4) 측정된 단면적과 비교**

| | 이 코드 | 측정 |
|---|---|---|
| σ_PbPb (5.02 TeV) | 7.644 ± 0.031 (stat) ± 0.22 (model) b | 7.67 ± 0.25 b (ALICE, arXiv:2204.10148) |
| σ_pPb (5.02 TeV) | 2.102 ± 0.033 b | 2.061 ± 0.080 b (CMS, arXiv:1509.03893; 오차는 계통·광도 합) |

둘 다 측정 오차 안. b_max = 20 fm 절단: 충돌한 사건의 0.2 %만 b > 18 fm라 절단 효과는 무시할 만하다.

  크게 다르다. 실험이 주변부(> 80–90 %)를 잘 쓰지 않는 이유이기도 하다.

## 4. 계통 불확실성

ALICE와 같은 변형: R ± 0.06, a ± 0.010, σ_NN ± 0.6, d_min 0 / 0.8 fm. 각 10 000 사건,
**기준과 같은 난수열**(아래 주의 참조). 기준 대비 상대 변화 ⟨N_part⟩ / ⟨N_coll⟩ (%):

| 변형 | σ_PbPb (b) | 0–1 % | 5–10 % | 30–40 % | 70–80 % |
|---|---|---|---|---|---|
| 기준 | 7.701 | | | | |
| R + | 7.811 | +0.1 / −1.9 | −0.3 / −2.0 | −0.3 / −1.0 | +0.5 / +0.8 |
| R − | 7.663 | +0.2 / +1.6 | +0.3 / +0.9 | −0.4 / +0.4 | −1.1 / −0.3 |
| a + | 7.743 | +0.1 / −0.7 | +0.3 / −0.6 | +0.8 / −0.3 | +1.6 / +2.6 |
| a − | 7.671 | +0.1 / +0.7 | +0.0 / +0.5 | −0.2 / +0.9 | −3.5 / −2.3 |
| σ_NN + | 7.709 | +0.0 / +0.8 | +0.1 / +0.9 | +0.2 / +0.7 | −0.4 / −0.0 |
| σ_NN − | 7.694 | −0.0 / −0.9 | −0.1 / −0.9 | −0.1 / −0.7 | −0.2 / −0.2 |
| d_min 0 | 7.707 | −0.0 / +1.4 | −0.0 / −0.2 | −0.0 / +0.1 | +0.6 / +2.3 |
| d_min 0.8 | 7.894 | +0.0 / −1.0 | +0.1 / −2.7 | −0.4 / −1.7 | −1.6 / −1.7 |
| *독립 seed (잡음)* | *7.755* | *+0.1 / −0.2* | *+0.4 / +0.1* | *+3.2 / +4.7* | *+13.4 / +18.5* |

- 중심(0–10 %): ⟨N_part⟩ ±0.3 %, ⟨N_coll⟩ ±2–3 % — N_coll이 핵 크기(R)와 hard core에 더 민감하다.
  σ_NN ± 0.9 %가 N_coll을 ±0.8 % 움직이는 것은 N_coll ∝ σ_NN 기대와 맞다.
- 주변(70–80 %): ±3–4 % (a에 가장 민감 — 핵 가장자리의 두께).
- σ_PbPb: 원천별 최대 변화의 제곱합 ±0.22 b, d_min이 지배 (0.8 fm에서 +0.19 b).
- 이 숫자들은 10k 표본이라 그 자체로 ~0.5 % 수준 잡음이 남아 있다. 정식 R_AA에 쓰려면 변형당
  40k 이상으로 다시 돌린다.

**주의 — 같은 난수열을 쓰는 이유 (troubleshooting #23)**. 처음에는 변형마다 다른 seed를 써서, 모든
변형이 주변부 ⟨N_part⟩를 같은 방향(+3–15 %)으로 올렸다. σ_NN +와 −가 같은 부호 — 물리가 아니라
잡음이었다. 중심도 경계 자체가 b의 백분위라 표본마다 ~0.1 fm 흔들리고, 주변부에서 N_part(b)가
가파르기 때문이다. 마지막 행(독립 seed 명목 표본)이 그 잡음의 크기: 주변부 효과보다 4배 크다.

## 5. 앞 모듈과의 연결, 다음

- **Module 2 → R_AA**: pp 13 TeV PYTHIA는 기준을 정했다. Pb–Pb 5.02 TeV의 기대 스펙트럼은
  ⟨N_coll⟩ × (pp 5.02 TeV). 0–5 %에서 ⟨N_coll⟩ ≈ 1.8 × 10³ (T_AA ≈ 26 mb⁻¹; 위 표 0–1, 1–4, 4–5 %의 가중 평균).
- **Module 4 → 배경**: ρ ∝ dN/dη ∝ N_part (대략). 0–10 %(⟨N_part⟩ ≈ 358)와 50–60 %(54)의 비는 ~6.6.
- **Module 5 → 냉핵물질**: EPS09 shadowing은 N_coll 스케일링 위에 곱해지는 보정. Glauber와 nPDF를
  합친 것이 "뜨거운 물질이 없을 때" R_AA의 기준선.
- **다음 (Module 7)**: PYTHIA Angantyr는 내부적으로 Glauber(+요동)로 N_part·N_coll을 정한 뒤 각
  하위 충돌을 PYTHIA로 생성한다 — 이 모듈의 결과와 Angantyr의 N_part 분포를 직접 비교할 수 있다.

## 6. 하지 않은 것 (알고 있는 한계)

- 회색 원반(gray disk)·핵자 하위구조(쿼크/핫스폿) 없음. 핵 변형(Pb-208은 거의 구형이라 영향 작음) 없음.
- 중성자 스킨(중성자와 양성자 분포의 반경 차이 ~0.2–0.3 fm) 없음 — 주변부에 % 수준 영향.
- 다중도 기반 중심도(N_part → NBD로 다중도를 만들고 거기서 백분위)는 N_part 순서로만 근사했다.
